<objective>
Wire the three event-bus observers to react to `AgentEvent.SkillActivated` (OBSV-04) and prove the `kore.skill.activate` span is correctly parented under the `kore.agent.run` span when the loop runs through `ObservableAgentRunner` (OBSV-03 parenting).

This plan closes the highest-risk gap in the phase: all three observers end their `when (event)` in `else -> Unit`, so adding `SkillActivated` compiles SILENTLY and the event is dropped — the compiler does NOT surface the missing branches. Each branch is therefore a deliberate task with a test, not a "compiler will catch it" assumption.

Purpose: Make the metrics path actually move a counter on skill activation (proven by test), keep the span observer from synthesizing a duplicate span, keep the dashboard module compiling, and verify span parenting end-to-end through the real runner.
Output: `KoreMetrics.skillsActivatedCounter` + duration recorder, the three observer branches, and a parenting test in `ObservableAgentRunnerTest`.
</objective>
