<objective>
Teach `KoreTracer.withSpan` to set a native OTel string-array attribute and publish the skill attribute-key constants on `KoreAttrs` (OBSV-03 support side). This is the observability-side complement to the literal-key span attributes emitted directly by `AgentLoop` in Plan 05-02 — `KoreAttrs` is the single source of truth for the `kore.skill.*` attribute keys, and any observability-side code (or future `KoreTracer` consumer) can now set a `List<String>` attribute without joining into a comma-string.

Purpose: D-03 requires `kore.skill.names` to be a real string-array (queryable per-element in any OTel backend), and `KoreTracer.withSpan`'s `Map<String, Any>` dispatch currently has no `List<String>` case. This plan adds it.
Output: `KoreAttrs.SKILL_NAMES/SKILL_COUNT/SKILL_DURATION_MS` constants and the `List<String>` branch in `withSpan`, with a test.
</objective>
