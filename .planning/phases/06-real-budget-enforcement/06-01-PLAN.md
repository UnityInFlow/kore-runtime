<objective>
Create the new `kore-budget` Gradle module: a Spring-free library whose `BudgetBreakerAdapter`
implements the existing, byte-identical `BudgetEnforcer` port (D-00) using budget-breaker's
`TokenTracker` (Tool 05, `io.github.unityinflow:budget-breaker:0.0.1`). The adapter keys one
`TokenTracker` per `agentId` (= `AgentTask.id` UUID) in a `ConcurrentHashMap`, mirroring
`InMemoryBudgetEnforcer`'s keying and no-eviction tradeoff (D-05). This delivers the real
hard-stop enforcement engine (BUDG-06) and per-agent isolation (BUDG-07).

Purpose: Replace the InMemory stub's logic with the real library behind the unchanged port,
so concurrent agents get isolated hard token budgets without any change to AgentLoop or the port.
Output: `kore-budget` module (build + adapter + tests), `settings.gradle.kts` registration.
</objective>
