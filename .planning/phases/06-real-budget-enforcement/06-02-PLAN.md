<objective>
Wire the `BudgetBreakerAdapter` (from plan 06-01) into Spring Boot 4 auto-configuration so a
developer enables real enforcement by adding the `kore-budget` dependency and setting
`kore.budget.enabled=true` — while `InMemoryBudgetEnforcer` remains the zero-config default
when the dependency is absent or the flag is unset/false (BUDG-05). Add a `BudgetBreakerAutoConfiguration`
inner @Configuration triple-gate to `KoreAutoConfiguration.kt`, mirroring `KafkaEventBusAutoConfiguration`,
add the `enabled` flag to `KoreProperties.BudgetProperties` (D-01 extensible shape), and wire
kore-budget as `compileOnly` + `testImplementation` in kore-spring (Spring-free adapter, D-06 resolution).

Purpose: Make real budget enforcement opt-in via one dependency + one property, with proven
bean-selection semantics and zero behavior change for existing apps.
Output: auto-config inner class, `enabled` property, build wiring, and the 4-scenario context test.
</objective>
