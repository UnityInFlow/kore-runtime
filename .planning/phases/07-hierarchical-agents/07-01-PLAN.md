<objective>
Lay the kore-core foundation for hierarchical agents: add the two defaulted
`AgentTask` fields (`depth`, `parentRunId`), the defaulted `AgentLoop.maxDepth`
constructor parameter, the D-05 best-effort `Cancelled` audit on the cancel path,
the `InMemoryAuditLog` recorded-run list, and the dispatch-time binding plumbing
that threads the current run's `task.depth` and `agentId` into any child binder in
`toolProviders` before the existing tool-dispatch block.

To keep this plan compilable standalone (wave 1, before `AgentTool` exists), the
bind seam is a tiny new interface `ChildDispatchBinder { fun bind(parentDepth, parentRunId) }`.
`AgentLoop` binds against `is ChildDispatchBinder`; `AgentTool` (Plan 03)
implements it. This removes the cross-plan forward reference (A2 binding, RESEARCH
Pattern 3 option 1, made type-safe).

This is the shared-file foundation — it is the ONLY plan that edits `AgentLoop.kt`,
`AgentTask.kt`, and `InMemoryAuditLog.kt`, so Plans 02/03/04 run on disjoint files.

Purpose: every later plan (storage threading, AgentTool, Spring config) depends on
these contracts existing. Binary compatibility (criterion #5) is preserved because
every new field/param is defaulted.
Output: modified `AgentTask.kt`, `AgentLoop.kt`, `InMemoryAuditLog.kt`; new
`ChildDispatchBinder.kt`; the existing `AgentLoopTest` continues to compile and pass
(criterion #5 proof), and `:kore-core:test` is green.
</objective>
