nullable, indexed `parent_run_id UUID` column on `agent_runs` with NO foreign key
(D-10 insert-ordering landmine, documented in the migration file), add the matching
Exposed `parentRunId` column to `AgentRunsTable`, write `task.parentRunId` in

integration tests to prove the column shape and the parent/child persistence.

(threaded in Plans 01/03) has nowhere to land in Postgres and run trees are not
reconstructable. Depends on Plan 01 only for the `AgentTask.parentRunId` field.
Output: V2 migration, modified table + adapter, extended MigrationTest +
PostgresAuditLogAdapterTest.
