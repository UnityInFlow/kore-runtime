# Milestone Audit: v0.0.2 — Hardening & Hierarchy

**Status: gaps_found** — 3/3 phases verified individually, but cross-phase integration of the
kore-spring auto-configuration boundary leaves the milestone's headline E2E value prop incomplete.

## Phase verifications (all passed in isolation)

| Phase | Status | Score |

| 07 Hierarchical Agents | passed | 5/5 |

## The central concern — three phases editing AgentLoop — RESOLVED CLEANLY

`AgentLoop.run`/`runLoop` composes all three phases without clobbering: Phase 5 skill span +
`SkillActivated` event, Phase 6 `budgetEnforcer.checkBudget`/`recordUsage`, Phase 7 per-coroutine
`ChildLineage` via `withContext`. The CR-01 race fix and CR-02 no-throw guard both landed correctly.
The in-process `agent { child { } }` flow (HIER-01/02/03/04) is fully wired and tested.

## The gap — the kore-spring factory boundary

`KoreAgentFactory` propagates `eventBus`, `auditLog`, `skillRegistry`, and `maxDepth` into every
agent — but **not** `BudgetEnforcer` and **not** `Tracer`. The auto-configuration selects the correct
beans (real `BudgetBreakerAdapter`, `KoreTracer`), but they never reach the agents the factory builds.
Net effect on the documented "add a Spring dependency and get it for free" flow:

| Capability | Spring path delivers? |
|------------|----------------------|
| Run-tree / hierarchy (HIER-01..04) | ✅ yes |
| Skill-activation OTel span (OBSV-03) | ❌ no — tracer never injected |
| Real hard-stop budget enforcement (BUDG-05) | ❌ no — enforcer never injected |
| Child inherits parent budget ceiling (WR-01) | ❌ no — still deferred |

## Recommended closure

A single small gap-closure phase wires the factory boundary:
1. Add `BudgetEnforcer` (optional, `@ConditionalOnMissingBean` default `InMemoryBudgetEnforcer`) and
   `Tracer`/`KoreTracer` params to `KoreAgentFactory` + the `koreAgentFactory` bean; have the factory
   call `budgetEnforcer(...)`/`inheritTracer(...)` before `block()`.
2. Add a `budgetEnforcer(...)` DSL override on `AgentBuilder` (needed for the factory to inject it).
3. Make `AgentBuilder.child` inherit the parent `budgetEnforcer` (closes WR-01).
4. Tests: a Spring-path KoreIntegrationTest asserting the injected enforcer/tracer actually fire
   (budget hard-stop + skill span emitted) through `factory.agent { }`.
5. Reconcile README.md:100-122 with the delivered behavior.

CR-03 (extractInput → kotlinx.serialization) remains acceptable tech debt for now.
